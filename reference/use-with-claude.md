# Use this hub with Claude

Claude makes a good study partner for this hub. It can quiz you, explain a part a different way, or help you apply a lesson to your own product.

## Point Claude at the hub

Pick whichever fits how you work:
- **In a chat.** Paste the link to [`llms.txt`](../llms.txt). It's a short map of every lesson and part, written for AI tools to read. Then paste the lesson you're working on, or upload its files.
- **In Claude Code.** Clone your fork and start Claude in that folder. It can read every lesson, the CSVs and the scripts directly.

## Things to ask

Copy one of these and change the details.

```text
Quiz me on lesson 06, Evals 101. Ask one question at a time, wait for my answer, then tell me what I missed.
```

```text
Explain Part 3 of lesson 02 like I'm new to this. Use the salon example and keep it short.
```

```text
Help me adapt the golden set from lesson 07 to my product. It's a support bot for a bike repair shop. Start with the must-pass cases.
```

```text
Check my PR description against lesson 04. Does the title name the outcome? Is anything missing from What, Why, How I checked it and Not in this PR?
```

```text
Ask me five questions from the interview question bank in a random order, like a real interview.
```

The last one draws on the [interview question bank](interview-questions.md).

A few habits that help:
- **Name the lesson and part.** "Lesson 09, Part 4" gets a better answer than "the CI one".
- **Say who you are.** "I'm a PM who's never used a terminal" changes the answer a lot.
- **Ask it to quote the lesson.** Then you can see exactly where an answer came from.

## Check what it tells you

Claude can be confidently wrong, the same way the salon bot can. [Lesson 2](../02-how-llms-and-agents-work/) explains why. If an answer doesn't match a lesson, trust the lesson and go read that part again. If you think the lesson's wrong, open an issue and tell me.
